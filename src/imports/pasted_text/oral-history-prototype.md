Design a high-fidelity UI/UX prototype for a new "Oral History" section of the Liberation War Museum (LWM), Bangladesh.

IMPORTANT CONTEXT

The Liberation War Museum already has an existing website. The new Oral History experience should feel like a natural extension of that website, NOT like a completely separate product.

I have provided a screenshot of the existing LWM website as a visual reference. Use it as the primary design reference for:
- Overall visual identity
- Color language
- Typography feel
- Rounded card shapes
- Spacing and visual hierarchy
- Image treatment
- Navigation style
- Museum/historical atmosphere
- Overall premium editorial feel

Do not copy the exact layout of the screenshot. Instead, create a modern information-archive interface that clearly belongs to the same organization.

PROJECT

Organization: Liberation War Museum (LWM), Bangladesh

Project Name: Oral History

The Oral History section will contain a very large collection of historical stories collected from people who experienced or witnessed the Bangladesh Liberation War.

Students from schools across Bangladesh collected these stories from people in their local communities and submitted them to the Liberation War Museum.

There are currently approximately 65,000+ stories.

The purpose of this website is to preserve, organize, search, discover, and read these historical stories.

CORE UX PRIORITY

The SINGLE MOST IMPORTANT UX REQUIREMENT is SEARCH.

The collection is extremely large, so users must be able to find relevant stories quickly and easily.

Users should be able to search using:
- Collector name
- Respondent name
- School name
- Area/location
- Words or phrases appearing inside the story itself

The search experience should feel extremely simple for an ordinary visitor, while still supporting powerful filtering for users who need more precise results.

Do NOT make the interface feel like a complicated enterprise database.

It should feel like a beautiful, accessible digital historical archive.

DESIGN DIRECTION

Create a visual language inspired by the existing Liberation War Museum website.

The reference website screenshot contains:
- A strong photographic museum background
- Warm historical imagery
- White/light content cards
- Rounded corners
- A restrained use of orange/golden accent colors
- Large editorial typography
- Museum photography and archival imagery
- Spacious layouts
- A premium but approachable visual style
- Strong contrast between historical imagery and clean modern UI

Carry this visual language into the Oral History experience.

The Oral History interface should feel:
"Historical + archival + human + trustworthy + modern"

Avoid:
- Generic SaaS dashboard aesthetics
- Excessive gradients
- Neon colors
- Overly futuristic UI
- Cryptocurrency/startup aesthetics
- Excessively dense tables
- Generic AI-generated website layouts

The design should feel appropriate for a national historical institution.

IMPORTANT UX PRINCIPLES

1. Search must be immediately visible.
2. Users should not need to understand the database to find a story.
3. Search and filtering should work together.
4. Story metadata should be easy to scan.
5. Long stories should be comfortable to read.
6. Historical material should feel respectful and archival.
7. Public users should clearly understand what they can and cannot access.
8. The experience should work for both casual visitors and researchers.
9. The interface should scale to 65,000+ stories.
10. Avoid clutter.
